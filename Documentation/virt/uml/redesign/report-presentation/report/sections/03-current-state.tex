\subsection{Landed Versus Open}

The branch contains substantial code and test infrastructure:

\begin{itemize}
  \item \texttt{arch/um/include/shared/backend.h} defines the backend
        contract used by host-side and kernel-side translation units.
  \item \texttt{arch/um/backend/seccomp/} and ptrace integration
        provide the non-\KVM{} backends.
  \item \texttt{arch/um/backend/kvm-v2/} contains the active \KVMvTwo{}
        implementation: vCPU, memory, syscall, exception, region,
        state-trace, LSTAR gadget; snapshot (Phase 1--6, with
        cmdline + debugfs bench harness) and record/replay
        (Phase 1--7, KUnit 7/7) primitives; KUnit suites for byte-shape,
        marshal, snapshot, and record.
  \item \texttt{arch/um/os-Linux/} carries the SMP-T78--T82 host-side
        resource-control levers: \texttt{MAP\_POPULATE} and
        \texttt{MAP\_LOCKED} on physmem, \texttt{mlockall},
        \texttt{madvise(MADV\_UNMERGEABLE)} on physmem,
        \texttt{MADV\_HUGEPAGE}/\texttt{NOHUGEPAGE} control,
        \texttt{/proc/self/oom\_score\_adj} write, optional
        \texttt{MAP\_HUGETLB} 2M/1G backing, and process-level
        \texttt{sched\_setaffinity}.
  \item \texttt{tools/uml/uml-launcher/} and \texttt{umlctl} provide
        host-side launch, supervision, gate, gate-loop, history, and
        deployment machinery, plus the new \texttt{[host\_resources]}
        TOML section (cgroup v2 limits + env var translation),
        cgroup module, preflight verification module, and the
        \texttt{mission} subcommand (6-phase acceptance gate).
  \item \texttt{tools/testing/selftests/um/} contains benchmark,
        parity, gate, soak (daemon-driven, 11 workload templates each
        carrying a default \texttt{[host\_resources]} block),
        snapshot, KVM record, ftrace, kprobes, KMSAN, and process
        reproducer coverage.
\end{itemize}

\subsection{Open State}

The important open items are bounded:
\begin{itemize}
  \item The 15-minute \texttt{umlctl mission} acceptance gate
        passes 6/6 phases including a 100/100 diverse-workload soak.
        The 24-hour continuous run remains as the long-tail
        wall-clock evidence; Tier 2/Tier 3 templates and LTP curation
        are wired into the soak daemon and need long-running confirmation.
  \item Snapshot Phase 1--6 and record/replay Phase 1--7 are in
        tree (memo 26 + memo 27); the remaining record/replay work
        is the host-side signal-interception wiring that turns a
        real SIGALRM into an \texttt{observe\_sigalrm} call (the
        log shape and replay-side gating are already proven by KUnit).
  \item The R14 Round-14 cache-flake closure (SMP-T73 YMM-upper
        XSAVE leak, plus T74/T75/T76 latent-bug follow-ups and the
        T77 feature-enablement checklist) is landed and validated.
        AVX-512 / AMX / PKRU / CET / AVX-VNNI un-mask remains
        future work; memo 52 §1--§2 documents the prerequisite
        check-list and the host-side levers shipped to ease it.
  \item The LKML queue is sequenced; Series 7 (kvm-backend) is now
        backend-layer unblocked by R14 closure and the new acceptance
        gate, pending cover-letter refresh and submission.
  \item Tier 3 host-resource features (SCHED\_FIFO RT, NUMA binding,
        \texttt{O\_DIRECT} for hostfs I/O) are deferred per memo 52 §3:
        the design is preserved, implementation opens only when a
        concrete operator question demands it (multi-tenant CI host,
        multi-socket bench rig, multi-UML memory-pressure soak).
\end{itemize}
