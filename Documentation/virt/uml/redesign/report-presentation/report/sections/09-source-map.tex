\section{Reporting Data Files}

The report and deck share normalized data under
\path{Documentation/virt/uml/redesign/report-presentation/data/}.
At this cutoff the important files are:

\begin{itemize}
  \item \texttt{bench\_speedups.csv} and \texttt{bench\_ratios.csv}
        for the eight-host post-gadget benchmark.
  \item \texttt{soak\_summary.csv} for the sustained-validation
        pilot (now subsumed by the
        \texttt{umlctl mission} validation run as the canonical
        artefact).
  \item \texttt{profile\_getpid.csv} for profile cost visualization.
  \item \texttt{workstreams.csv}, \texttt{validation\_ladder.csv},
        \texttt{upstream\_queue.csv}, and \texttt{status\_kpis.csv}
        for status tables.
\end{itemize}

Reproducing the canonical validation artefact:

\begin{verbatim}
$ umlctl mission --kernel <path-to-uml-binary>
PASS kunit            -- 10/10 KUnit cases PASS
PASS bench            -- capture=35us median=13us
PASS substrate        -- cpython-tier0 PASS
PASS host_resources   -- env knobs applied silently
PASS soak             -- 100/100 PASS; 0 panics
PASS diagnostic       -- metadata captured
MISSION_ACCOMPLISHED in 867s (kernel=9ccbf5e7bb58, host=<H>)
\end{verbatim}

JSON scoreboard at \texttt{<out>/scoreboard.json}. \texttt{--quick}
skips the diverse-workload soak for $\sim$12-second development
checks. \texttt{--continue-on-fail} runs all six steps regardless
to collect every signal in one pass.
